# 🌤️ Weather Forecaster

Bash-скрипт для получения текущей информации о погоде в выбранном городе.

📌 Описание

Скрипт запрашивает у пользователя название города, после чего получает и выводит информацию о погоде в этом городе.

Например, пользователь вводит:

Italy

Скрипт показывает доступную информацию о погоде, включая:

- 🌡️ Температуру
- 💨 Скорость и направление ветра
- 💧 Влажность
- ☁️ Состояние погоды
- 🌡️ Ощущаемую температуру
- 📊 Дополнительную информацию о погоде

🛠️ Технологии

- Bash
- Linux
- Command Line
- API

🚀 Запуск

Клонируйте репозиторий:

git clone git@github.com:MrN1r/Weather-Forecaster-git.git

Перейдите в директорию проекта:

cd Weather-Forecaster-git

Сделайте скрипт исполняемым:

chmod +x weather.sh

Запустите скрипт:

./weather.sh

После запуска введите название нужного города.

🎯 Цель проекта

Проект создан для практики Bash, работы с Linux, командной строкой и получения данных через API.
